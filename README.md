# بوت هدايا تيليجرام (Stars Gift Bot)

المشروع يشغّل بوت واجهة عادي مع حساب Userbot عبر Telethon لإرسال هدايا
Telegram Stars الفعلية من رصيد الحساب المضيف.

## الملفات

- `main.py`: نقطة التشغيل وتحميل متغيرات البيئة وتهيئة البوت واليوزربوت.
- `front_system.py`: واجهة البوت، اختيار الهدايا، إدارة الكتالوج، والأوامر السريعة.
- `backend_system.py`: التحقق من المستخدم وتنفيذ إرسال الهدية عبر MTProto.
- `gifts.json`: كتالوج الهدايا المتاحة، ويُحفظ داخله أيضاً اختيار الهدية التلقائية.
- `generate_session.py`: توليد `SESSION_STRING` محلياً.

## الأوامر

### داخل خاص البوت

- `/start`: فتح الواجهة الرئيسية.
- `/rgift`: إعادة تحميل `gifts.json`.
- `هدية @username`: يثبت المستخدم المستهدف ثم يعرض كتالوج الهدايا لاختيار الهدية وإكمال الإرسال.

مثال:

```text
هدية @username
```

الأوامر متاحة فقط للمتحكمين الموجودين في `OWNER_IDS`. ويمكن إبقاء `OWNER_ID` القديم إذا كان لديك متحكم واحد فقط.

### داخل محادثة خاصة من حساب اليوزربوت

#### إرسال الهدية التلقائية

```text
ارسال
```

يحذف اليوزربوت رسالة الأمر ويرسل الهدية المحددة من:

`⚙️ إدارة الهدايا` → `⭐ هدية تلقائية`

إذا لم تكن هناك هدية تلقائية محددة، لا يتم إرسال أي هدية وتصل رسالة تنبيه إلى Saved Messages.

#### تحديد الهدية بالإيموجي

```text
ارسال 🎁
```

أو أي إيموجي مربوط بهدية في `gifts.json`.

- الإيموجي العادي يطابق حقل `emoji`.
- الـ Custom Emoji يطابق `document_id` مع `custum_gift_icon` للهدية.
- الإيموجي المكتوب مع الأمر يتغلب على الهدية التلقائية لهذه العملية فقط.

إذا لم يجد البوت هدية مطابقة، لا يرسل شيئاً ويضع الخطأ في Saved Messages.

## إدارة الهدايا

من الشاشة الرئيسية يوجد زر `⚙️ إدارة الهدايا`، ومنه يمكن:

- إضافة/تحديث عدة هدايا ضمن جلسة واحدة، رسالة بعد رسالة.
- عرض الهدايا داخل جدول Rich Message يحتوي زر إزالة لكل هدية + الإيموجي البريميوم + `gift_id`.
- تحديد الهدية التلقائية التي يستخدمها أمر `ارسال` بدون إيموجي.

عند الضغط على `🎁 إضافة/تحديث هدية` يبدأ البوت جلسة إضافة مستمرة. أرسل أو حوّل أي عدد من رسائل الهدايا، كل رسالة بهذه الصيغة:

```text
🧸 **50**⭐️— `5974210632977745012`
```

- `🧸` يكون Premium / Custom Emoji الخاص بالهدية.
- `50` هو السعر بالنجوم.
- `5974210632977745012` هو `gift_id` الحقيقي للهدية.

يستخرج البوت `custom_emoji_id` تلقائياً من Entity الخاص بالإيموجي البريميوم. التنسيق الغني مثل **Bold** و`Code` مسموح. إذا كان `gift_id` موجوداً مسبقاً، يتم تحديث الإيموجي والسعر بدل إنشاء نسخة مكررة. بعد كل رسالة يبقى البوت في وضع الإضافة ويعرض عداد الهدايا المضافة/المحدثة، ولا تنتهي الجلسة إلا عند الضغط على زر `✅ إنهاء`.

نظام القسائم غير موجود في هذه النسخة.

## متغيرات البيئة

```env
BOT_TOKEN=...
API_ID=...
API_HASH=...
OWNER_IDS=123456789,987654321,555555555
SESSION_STRING=...
GIFTS_VOLUME_PATH=...
```

لأدمن واحد فقط يمكنك استخدام `OWNER_ID=123456789` بدل `OWNER_IDS` للتوافق مع الإعداد القديم.

لا يوجد `DEFAULT_GIFT_ID` بعد الآن؛ اختيار الهدية التلقائية يتم من داخل البوت ويُحفظ في `gifts.json`.

عند التشغيل المحلي يمكن ترك `GIFTS_VOLUME_PATH` فارغاً/غير موجود؛ سيستخدم
المشروع `gifts.json` الموجود بجانب `main.py` تلقائياً.

## التشغيل

```bash
pip install -r requirements.txt
python generate_session.py
python main.py
```

على Railway يمكن ربط Volume بملف الهدايا مثلاً:

```env
GIFTS_VOLUME_PATH=/data/gifts.json
```

`SESSION_STRING` يمنح وصولاً إلى حساب اليوزربوت، لذلك يجب عدم نشره أو إضافته إلى مستودع عام.
